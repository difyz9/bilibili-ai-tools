# AI 影视导演工作流（AI Film Director）

> 源自《AI导演思维课》14 集视频课程听录提炼。核心理念：**市场缺的不是会用 AI 的人，而是懂 AI 导演思维的人**——能确定主题、拆解剧本、设计分镜、控制构图/光影/人物/运镜/节奏，把零散画面变成能交付的成片。

## 核心工作流

```
需求 → 确定主题 → 拆解剧本 → 设计分镜 → 造型设计（人物+场景）
     → 分镜图片制作 → 图生视频（首帧/首尾帧）→ 配音配乐 → 剪辑成片
```

**关键原则**：
1. **先图后视频**：改构图/角度/布光，先用图生图改静态图再图生视频，成本最低、最可控
2. **几乎不用文生视频**：主体/场景/风格/视角在分镜图阶段解决，视频阶段只用首帧图生视频
3. **提示词五要素**：视觉背景 + 运镜描述 + 画面细节补充 + 情绪提示 + 参数设定
4. **镜头衔接法则**：180度法则（不越过两人中轴线）+ 30度法则（镜头移动至少30度，避免突变感）

## 工具速查

| 用途 | 工具 |
|---|---|
| 图生图/改构图角度布光 | Nano Banana、即梦、可灵；有条件 GPT Image 2；传统 Midjourney、SD |
| 视频生成（主力） | **Seedance 2.0**（全能参考/首尾帧，长镜头首选）|
| 视频生成（简单画面） | 海螺AI、Vidu 3、可灵、即梦、开源**通义万相 Wan 2.2** |
| 运镜模板 | 可灵、即梦（含希区柯克变焦模板）|
| 生图（免费） | 豆包AI（三视图、造型设计）|
| 配音 | 智影 TTS（情绪音色）、剪映「换音色」、即梦数字人对口型 |
| 配乐 | MiniMax（音乐生成）、剪映音乐库 |
| 剪辑 | 剪映（叠化转场、识别字幕、环境音）|
| 本地开源视频生成 | ComfyUI + 万象2.2 / CogVideoX / LTX / OpenSora |

## 常用提示词模板

### 分镜图片（画面主体 + 构图视角 + 环境氛围 + 光影 + 风格）
```
全景，一位侦探站在雾气弥漫的街道中央，中心构图，低角度仰拍，冷色调夜景，赛博朋克风格
```

### 视频生成（主体动作 + 风格氛围 + 镜头视角 + 运动/运镜描述）
```
红衣女子在巴黎街头优雅旋转，电影风暖色调，低角度仰拍缓慢推进
```

### 人物造型（豆包AI）
```
参考脚本，设计脚本中出现的三个人物形象（XXX），要求具体到发型、服装、长相、身材特征，符合身份定位、短剧风格。三视图同图、白色背景、16:9、写实风格
```

### 长镜头一镜到底（Seedance 2.0 全能参考）
```
一镜到底，按参考图顺序从图一自然过渡到图二、自然转场到图三
```

## 过审技巧（真人短剧）
1. 规避敏感题材（婚姻破裂/金钱纠纷/情感拉扯）
2. 敏感词同音字替换（如"离婚"）
3. 提示词首句加"正确价值观、正能量剧情、无负面情绪、无肢体冲突、符合公序良俗"
4. 服装场景干净得体
5. 避免"图片中的男人/女人"性别表述，用"图片1和图片2的形象"代替
6. 遇违禁词就同义词替换（平台不提示是哪个词）
