## 一、镜头语言使用与调度（p06）

### 1. 运动调度（镜头与角色的运动方式）
- **镜像移动（朝向镜头的纵向运动）**：人物冲向镜头、镜头跟随人物后侧。例：《1917》片段。→ 极大提升画面的**压迫感和紧张感**。
- **横向移动**：镜头横向移动穿过不同空间，像横版过关游戏。例：《穿越XX》电影片段。→ 很好地表达**角色与环境之间的关系**。
- **对角线移动**：人物沿对角线从画面远处移动到近处，再通过摇镜让角色同样沿对角线从近处跑到远处。→ 模拟真实拍摄、兼顾人物与环境关系，**汽车影片拍摄中非常常用**（镜像、横向、摇镜、对角线都常见）。

**应用选择**（以操场奔跑为例）：
- 选镜像运动 → 画面富有活力，像宣传片；
- 强调人与操场关系、放大环境权重 → 选横向运动；
- 模拟真实拍摄、兼顾人景关系 → 选对角线运动。

**关键案例**：小巷人物被追逐场面——直接让 AI 生成很平淡；先安排运动调度、设计好每个镜头的角色运动和相机拍摄位置，多机位多角度画面就变得紧张刺激。

### 2. 人物朝向调度（传达情绪）
设计片段拍摄时**有意安排人物朝向**来传达不同情绪：
- **正面朝向镜头逐步拉近** + 精湛面部表情 → 从容又极具压迫感（例：《沉默的高洋》中人物走向镜头几乎无对话却充满紧张）。
- **静态主角 vs 横向动态路人**的朝向对比 → 凸显主角的无助感（例：《活着》中主角被来来往往的路人衬托出孤独无助）。
- 各角度效果：
  - 正侧面 → 常规的主角特写；
  - 纯侧面 → 第三者身临其境的感觉；
  - 后侧面 → 既能看到主角动作行为，又能看到主角前方场景，主要作用是把观众带入主角视角；
  - 正面 → 更好地感受主角的情绪表达；
  - 侧45度 → 兼顾情绪表达，画面更自然立体；
  - 纯背面 → 看不到表情也看不到内容，营造孤独感和距离感。

**应用**：雨夜车站雨棚下等车的少女——直接在提示词中控制相机位置来拍摄人物不同朝向，孤独感更鲜明。工具推荐 **Seedance 2.0（C-S2.0）**，可灵等模型不同场景各有优势，哪个好用用哪个。

### 3. 人物站位调度（高低差强化关系）
- 导演常让**处于主导地位的角色处在较高位置**，用仰视拍主导者、俯视拍被动者，强化人物之间的主动/被动关系。
- 案例（巫师/杰洛特对话）：两人无高度差 vs 让杰洛特站起身来——后者冲突性更明显，观众能感到**高位者掌握主动权**。

### 4. 距离调度（人物关系的远近）
- 通过人物之间的距离塑造情感关系（常用且好用）：
  - 离得远 → 疏离（教室两端，无台词也能感到疏离）；
  - 靠近 → 关系缓和；
  - 紧挨坐一起 → 亲密无间。
- 电视剧经典画面：两人并肩而立关系很近，男主把烟叼到自己口中进一步拉近关系；女人走开距离拉远，意味着她无力帮助眼前男人——距离表达了人物内心的关系。

### 5. 景深结合（近景+远景同框调度）
- 同一画面中安排两人分别位于**近景和远景**，让情绪在近远景中流转，同时交代两人关系和情绪，高效传达信息。
- 案例：地下室被绑女人（只知被绑）→ 前景加一个正在打电话的男人 → 观众立刻获得"绑匪是谁、绑匪在做什么"的信息。

## 二、AI人物质感提升5大技巧（p07）

主题句：**肢体动作、运镜、皮肤、人物外观、人物情感**。

### 1. 肢体动作与面部表情的精确控制
- 人能做出丰富表情，连鼻子耳朵都有轻微精确的运动，但 AI 默认**忽略很多自然的细微动作**，这是"AI味"浓的原因。
- 案例（小丑脸谱）：直接写"放声大笑"效果一般；拆解一系列行为、**精确指出面部具体哪个位置如何运动**，配合指定动作 → 表现力上升几个档次。
- 配合肢体动作：
  - 公园吃醋女生：加"转头、视线移开、翻白眼" → 生气嫉妒感立刻出来；
  - 客厅抽烟的颓废男人：抽烟喝酒基础上加"直接倒向后方的沙发" → 颓废无力感更强烈。

### 2. 运镜符合画面心境
- 小丑：镜头拉近且不断旋转 → 眩晕感，更惊悚；
- 手术场景：镜头快速拉近 → 观众像在现场的医生助手，身临其境。

### 3. 皮肤质感（去AI味的关键）
- AI 默认皮肤**过于光滑细腻**，像精修过的广告明星。
- 提示词加入：**毛孔、真实皮肤纹理、轻微斑点** → 对比下皮肤立刻真实，AI 味大减。
- **适配环境的皮肤状态**：藏族服饰小男孩加"高原红" → 从游客变本地人。
- 哭泣女人：加"**通红的眼眶、泛红的鼻头**" → 不再是电视剧里假哭的样子。
- 要点：皮肤泛红、流汗、泪痕、出油等细节 AI 不会主动生成，**要根据人物所处环境气候手动添加描述**。

### 4. 人物外观（造型细节）
- 圣诞老人缺"大胡子" → 加上后不再违和；
- 水池边拍艺术照的女人：泳装却身上一滴水也没有很怪 → 让头发浸湿、身上布满水珠 → 从网红拍摄现场变成真实生活分享。

### 5. 人物情感（情绪的精准控制）
- **用程度词限制表现幅度**：如"开心大笑"→"微微一笑"，情绪控制更精准；
- **描述细腻的情绪变化**：不只写"悲伤哭泣"，改为"眼神先是哭泣后的空洞与麻木，随后闭了一下眼、低下头" → 反应更细腻真实。

## 三、AI视频电影感8大技巧（p08）

### 1. 五官与情感表现（精确表情控制）
- 大笑的小丑加**歪头杀 + 眼神凌厉** → 邪恶感大增；
- 小丑从放声大笑改为**温暖的微笑** → 精确表情控制让画面更合理。

### 2. 肢体动作细节
- 公园吃醋女生：动作描述改为"转身、翻白眼" → 更自然；
- 在家喝闷酒的男人：动作换成"向后靠" → 颓废弱势感大幅提升。

### 3. 环境互动细节（动作与环境的交互）
- 喝咖啡的人：咖啡滚烫冒白烟 → 喝之前**对着杯口吹一口气** → 动作更自然；
- 冰天雪地拿保温杯：让白烟**从保温杯和嘴巴里都大量喷出** → 环境感觉低了几度；
- 悲伤哭泣：眼圈通红、鼻尖微红 → 还原真实哭泣感。
- 原则：**特写时这些细节尤其重要**，有一处不合理就有浓浓 AI 味；生成前先想象自己平时是怎么做的。

### 4. 运镜技巧：还原第一视角（镜头跟随拍摄）
- 早期 AI 视频里"镜头跟随拍摄"让视频格外真实。蜜蜂：镜头缓缓推进+蜜蜂向前飞 → 带入感差；改为**镜头跟踪拍摄** → 带入感强烈。
- 照镜子的女生门口闪过黑影：加人物表情和回头动作 → 紧张氛围提升。
- 台词不多的桥段，往往靠这类运镜强化叙事。

### 5. 制造环境干扰（让人物融入画面）
- 女生看书/独处：环境中加入**蝴蝶从镜头前飞过**，人物自然被吸引 → 画面立刻真实；
- 街边乞讨的乞丐：加上来往路人 → 营造孤独感；
- 人群中行走的主角：加路人并**刻意让路人"打散"、主角"不打散"形成区分** → 效果强化；
- 靠窗的女人：转身看窗外 + **风吹动窗帘** → 人与环境融合。
- 蝴蝶飞过、风吹、人群走过都是生活常见细节，能极大增强真实感。

### 6. 人物契合环境（生图时）
- 工地搬砖的男人：服装整洁、面庞干净显然不符 → 让人物**流汗、一脚沾满尘土** → 契合环境；
- 藏族小男孩：皮肤要符合当地**紫外线强度**（晒痕/高原红等）。

### 7. 皮肤质感细节（承上）
- 总结增加皮肤质感的提示词（毛孔、纹理、斑点、泛红、出油等），让生成的皮肤更真实。

### 8. 符合物理定律
- 海边悬崖的女人：陆地和海面持续产生温度差 → **海边风几乎不间断** → 风吹动头发衣物的画面自然合理。
- 提示：生成的视频要符合自然的物理定律才不违和。

## 四、AI人物造型设计要点（p09）

分三部分：基本提示词结构 / 生成技巧 / 修改技巧。

### 1. 基本提示词结构
**人物设计提示词**（上传分镜脚本到豆包AI）：
> "参考脚本的内容，设计脚本中出现的三个人物形象（张浩、苏琴、助理），要求具体到**发型、服装、长相、身材特征**；要求设计的角色**符合脚本中的身份定位、短剧风格**。"

- "身份定位" → 让人物之间形象区分更明显；"短剧风格" → 锁定美术风格契合短剧使用。
- 示例：苏琴 = 完美女主形象；张浩（落魄前夫、自私算计）= 油腻且杂乱的发型、廉价的深蓝色西装外套、国字脸面部浮肿、中等身高微胖——鲜明的反派特征；助理 = 设计克制、符合刻板印象。
- 坑：设计给出**两个方案混杂**不利于后续生成图片 → 应只保留一种设定（如"助理设定为女，只保留女性提示词描述"）。

**场景设计提示词**（同样上传脚本）：
> "参考脚本内容，设计脚本中出现的场景，要求场景符合脚本描述的剧情氛围，**画面中预留各个人物的位置，但不要出现人物，只描述场景**。"

- 生成结果含核心区域（如靠窗餐桌）+ 辅助场景细节（地面与软装、门区与远景）→ 可作开场**空镜头**交代故事发生背景。

### 2. 人物/场景造型生成技巧
- **一次只生成一个人物**（一次性生成所有人物容易杂糅、互相串台）。
- 用豆包AI图像生成，提示词里交代呈现形式：**"生成三视图，在同一张图片上，白色背景"**，比例选 16:9（更适合三视图），风格选写实（人像摄影 / 电影写真）。
- **多生成几次挑选**：三视图常见错误——背视图出现开口、侧视图发型与正/背视图不一致等。
- 细节一致性难点：手腕/手指上的手镯、戒指，左右区分，细节花纹——保持一致性很难，效果不佳时直接在提示词中删改（如删去"豆沙色口红"过于鲜艳的描述、删去手镯戒指等装饰；豆包关联上下文，直接文本要求"删去……"即可重新生成）。
- 场景图比例按发布平台：长视频平台 16:9；短视频/手机平台 9:16 或 4:3。
- 坑：模型理解有限，要求"不出现人物"仍可能生成出人物 → 需要修改。

### 3. 造型修改技巧（参考图生图）
- 找到大部分满意的图片 → 下载 → 作为参考图上传 → 用提示词描述修改（如"将图片中的所有人物都消除掉，只保留场景"）。
- 参考图生图还能**改变视角**：如"生成参考图四个不同角度拍摄下的画面"（俯视角度、单个人物角度、镜头拉远角度），多生成几遍可得更多角度。

### 4. 文件管理习惯
- 单独建一个总文件夹放所有短剧资料：人物设计、场景设计、分镜视频片段、分镜脚本；
- **分镜图片直接放总文件夹**（使用频率最高，避免每次进子文件夹查看）。

## 五、真人短剧分镜头图片制作流程（p10）

分三部分：提示词基本结构 / 人物与场景合成技巧 / 修改案例。

### 1. 提示词基本结构 = 画面主体 + 构图视角 + 环境背景与氛围 + 光影氛围 + 风格与质感
- **画面主体**：即上节课生成的人物造型设计 + 场景造型设计；
- **构图与视角**：中心构图、低角度仰拍、仰拍等；
- **环境背景与氛围**：如咖啡厅的温馨惬意；
- **光影与氛围**：设定光线来源、色调，用来调整整体情绪；
- **风格与质感**：赛博朋克风格、高对比度风格、霓虹灯光效果等。

示例提示词：
> "全景，一位侦探站在雾气弥漫的街道中央，中心构图，低角度仰拍，冷色调与夜，赛博朋克风格。"

参数注意：部分平台（如 Midjourney、具图像生成功能的大语言模型）不能点选参数，**需要在提示词里写参数描述**。

### 2. 人物与场景合成技巧（参考图生图）
- 将人物三视图设计图 + 场景图（如高档咖啡厅）分别上传为参考图，提示词写"**套用参考图片二（场景）、人物参考图片一（人物）**"。
- 即梦AI 参考图生图支持 **@ 键呼出小窗选择素材**（想参考场景选场景、想参考人物选人物），比直接说"图一/图二"更精准。
- 参数：宽高比 16:9；分辨率 **2K 即可**（4K 图生成视频时不支持，没必要）。
- **常见问题（两张图融合时）**：人物小腿比例变粗错误、面部清晰度远不如场景、结构崩坏（左右不对称、眼睛一大一小）；场景姿势要求越复杂越容易出现。
- **改进方案**：先只参考人物（删掉场景参考图）让**人物与场景一并生成**，人物比例正常、结构无崩坏；再下载该图，用参考图生图**消除画面中的人物**来获得对应场景。

### 3. 分镜图片修改案例（两种方式）
- **方式一：与预想差距大、无法基于原图修改**（提示词描述不到位）→ 修改提示词补全信息；若模型训练参数不支持（如现实咖啡厅一般没有包间，模型标定缺失），**以生成结果为导向直接修改脚本内容**（如把"助理推门而入"改为"助理走到苏琴身边"）——随机应变，这种场景在创作中很常见。
- **方式二：90%以上满意、只调小细节** → 参考图生图：下载图片作参考图上传，提示词只写要调整的部分（如"将图片中的时间改为夜晚"、"让人物背对镜头坐在靠近镜头一侧的椅子上"）。
  - 注意：修改成功率与修改内容难度相关，**有时不如一开始就写好提示词**；单张图片**避免修改次数过多**（清晰度与逻辑逐次降低，改两次基本无法作为视频素材）。
- **超清处理**：即梦AI 修改过一次的图建议做超清——动漫/2D/3D 风格选"超清"（"智能超清"会过犹不及、生成太多细密花纹、长相特征变化）；**写实图片选"智能超清"**（可放大到4K，面部细节从崩坏模糊变超清）。
- 坑：超清后可能随机出现细节变化（如光腿变成穿丝袜）→ 多生成几次并留意小细节。

### 4. 文件管理
- 分镜图片放总文件夹，**按时间顺序用数字标号命名（01、02…）** → 生成视频时按顺序快速找到素材，条理清晰。

- 所有课程素材/提示词/文档均随视频发布在评论区置顶自取；
- 图片生成工具：豆包AI（免费）；视频/图片生成平台：即梦AI、Seedance 2.0、可灵等；
