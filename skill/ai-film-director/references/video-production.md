## 一、真人短剧视频生成（p11）

### 1.1 视频生成提示词结构
- 完整提示词 = **主体动作与场景 + 风格与氛围 + 镜头与视角**
- 例：一位穿着红色连衣裙的年轻女子，在撒满阳光的巴黎街头优雅旋转；电影风格、暖色调；镜头从低角度仰拍并缓慢向前推进。
- 与生图提示词相比只多两部分：**画面中事物的运动描述** + **运镜描述**。
- 关键认知：**几乎不用文生视频**（不确定性极高）；主体/场景/风格/氛围/视角在分镜图片阶段已解决，视频阶段只用 **首帧图生视频 / 图片参考生成视频**。

### 1.2 平台分类
- **闭源平台**：RUNWAY、MEDUGORNY（国外）；可灵、即梦（国内）。
- **开源平台**（本地运行、免联网、高配机器几乎零成本）：万象2.2、CogVideoX、LTX、OpenSora 等。缺点：时长、清晰度、功能局限性大，效果远不及闭源。
- 目前主流 = **即梦平台 + Seedance 2.0 模型**（业内生成效果最好的模型之一）。
- 内容限制：闭源平台对部分画面有限制；开源本地运行几乎什么都能生成。使用最多的是**万象2.2**（契合 ComfyUI 生态）。

### 1.3 即梦AI 基础操作
- 首页 → 左侧「生成」→ 底部下拉菜单把生成模式切为「视频生成」。
- **文生视频**：直接输入提示词；模型默认 Seedance 2.0；简单画面（固定镜头、人物说一句话/小动作）可选更快的 3.5/3.0 模型。
- **首尾帧生成（最常用）**：上传一张图作为视频开头画面，AI 延续后续内容；时长可选 **5 秒 / 10 秒**。
- **智能多帧模式**：除首帧外可补充上传中间帧画面（如"坐着→起身→离开画面"逐帧做图），比单纯首尾帧更稳定。
- **主体参考**：类似参考图生图，单独传人物+背景再描述互动。属冷门功能、效果不尽人意；不如生图时就把人物和场景结合好，再用首尾帧图生视频更精准。
- **全能参考**：Seedance 2.0 专属功能（详见第二节）。
- 对比演示：文生视频逻辑弱（人物转身后多出一张脸）；图生视频构图、光影、质感远胜。生图模式下动作/运镜描述可留可删（图片不会动，会自动忽略）。
- 生图一组 4 张，视角/设计/背景/打光各有区别，选择空间大；点图片下方播放图标可快速加入视频生成预备栏。
- **素材管理**：每个片段生成后存入专属文件夹，**按数字从小到大命名**，便于剪辑时按脚本时间顺序导入。

### 1.4 本地开源方案（ComfyUI + 万象2.2）
- 下载 ComfyUI（推荐"绘世启动器"），一键启动后在浏览器打开操作页。
- 左侧窗口有各种工作流模板，首页选 **Image to video**（图生视频，默认万象2.2）。
- 首次运行提示缺失模型/文件 → 点「下载」跳转下载页；放置位置有提醒（如 UNET 模型放 ComfyUI 根目录 models 文件夹）；放对后重启即可运行。
- 生成逻辑：左侧上传图片 → 中间写提示词 → 右侧输出视频，点 RUN 运行。
- 预期管理：质量与主流闭源模型差距不小、功能少，主要用于图生视频生成 **5 秒片段**。

## 二、Seedance 2.0 制作短剧片段思路（p12）

### 2.1 传统图生视频的局限
- 首帧/首尾帧图生视频要求先把人物与场景**合并成一张分镜图**，才能让人物做动作 → 效率低；复杂场景、人物与场景交互时，提前修图非常困难，需要专业美术知识和软件操作技巧。
- 例：AI 影片只有人物家中、院落、埋宝藏三个场景，若按传统方法仍需逐镜合成人物+场景图。

### 2.2 全能参考：像真拍短剧一样做 AI 视频
- 思路 = **"请演员 + 定场地 + 导演口头交代"**：
  1. 把提前做好的**男主角、女主角三视图**上传到图片参考窗口；
  2. 把**场景参考图**（如咖啡厅装修/设计样式）上传到参考图窗口；
  3. 提示词用自然语言像导演给场务/演员交代镜头一样描述，引用图片用 **@键** 唤起菜单选对应图片（如"使用图片1和图片2的形象"）；
  4. 提示词示例：*"使用男主角形象和女主角形象生成视频，内容是两个人在咖啡厅对坐交谈，咖啡厅风格参考图片三。第一个镜头：男主角（图片中的人物）坐在桌前期待讨好地说【台词】；第二个镜头：女主角（图片中的人物）声音平淡没有情绪地说【台词】"*。
- 效果：人物凳子款式、咖啡厅装修、人物身后背景**高度逻辑严谨、设计一致**；人物对话可直接生成，**音色贴合人物形象气质**。

### 2.3 参数设置
- **时长**：先用手机计时器带入角色、有感情地朗读台词估时长；Seedance 2.0 最长可设 **15 秒**（示例两个镜头选 15 秒一次生成）。
- **模型版本**：Seedance 2.0 Fast（生成更快，但画质偏低、表现力弱）vs Seedance 2.0（效果更好），按需求选择。

### 2.4 真人视频过审技巧
1. 内容上规避敏感题材：婚姻破裂、金钱纠纷、情感拉扯等负面情绪过重的剧情易被拒。
2. **敏感词替换**：如"离婚"换成同音字写法。
3. 提示词第一句加正向声明：如"正确价值观、正能量剧情、无负面情绪、无肢体冲突、符合公序良俗"。
4. 画面设计：服装、场景干净得体，不过度暴露。
5. 提示词**避免"图片中的男人/女人"等性别表述**（平台对性别对立审核严），用"使用图片1和图片2的形象"代替——图片自带性别特征。
6. 技巧非绝对：偶发"正常词也被判违规"，此时就做同义词替换（平台不会指出具体是哪个词）。

### 2.5 Seedance 2.0 进阶能力
- **单张图片出多角度多运镜带切镜的视频**：提示词描述镜头跟随+主体动作，再列出几个切镜（如废土战车示例：镜头跟随战车在荒野行驶扬起沙尘 → 切镜①后座乘客举枪朝天开枪正面特写 → 切镜②远景俯视一只鹰在天上飞 → 切镜③正面视角车辆左侧突然爆炸、加速急转灵巧躲过爆炸）。单图即可生成一致性高、带切镜的视频。
- **视频参考动作模仿**：上传参考视频+角色图，提示词如"图片中的人物对着镜头持续破口大骂，人物表情和动作细节全部参考视频"。**长流程、复杂动作模仿时，要把人物行为从头到尾完整描述一遍**（例：先走一段→对路边橱窗照镜子→转身过马路→举手示意→在自己汽车旁停下→过马路后挥手做请的动作让出租车先过）。
- **特效增强**：发光粒子等特效自然流畅，特效颜色、路径与人物演艺高度契合，效果远超很多低成本 3D 短片。

## 三、配音配乐（p13）

### 3.1 核心原则
- 配音最重要的是**带人物情绪**：旁白只要机械朗读即可（多数 TTS 都能做）；人物台词必须匹配剧情氛围的感情。

### 3.2 智影（TTS 配音平台）
- 输入台词文本 → 右上方选音色：**官方音色**（大部分免费、可选择性多）+ **音色市场**（真人/配音演员音色）；点头像试听，合适即"添加和使用"。
- 音色下方有**情绪下拉菜单**：多种情绪类型，每种下再分细分项（如"难过/气势"等），选项丰富；示例台词选"怨怼"情绪。
- 可调参数：**情绪、说话语气强度、语速、语调、音量**——先生成一次试听，再按听感微调。
- 局限：复杂情绪（悲伤中带开心、绝境中带希望）覆盖不到 → 改用**真人配音 + 音色转换**。

### 3.3 真人配音 + 剪映换音色（保情绪、换音色）
- 自己先配音（情绪到位但音色不符，如中年离婚男人形象）→ 剪映剪辑轨道选中该音频 → 右上方参数区出现「换音色」→ 选分类（如男声）→ 逐个试听（如"沉稳青年音"）→ 几秒完成 8 秒音频转换。
- **换音色不挑原始音色**：智影生成的音频音色不合适，也可回剪映二次转换。

### 3.4 旁白配音
- 剪映直接生成：左上「文本」→「添加口播稿子」→ 输入文本 →「配音选择」选音色（如温柔女生）→ 生成朗读自然流畅、气息平稳的旁白。

### 3.5 对口型（即梦「数字人」模式）
- 左侧上传视频/图片（会做**角色检测**，建议人物近景特写、辨识度高），右侧上传音频（**最长 30 秒**，超长上传失败）。
- 需写动作描述+运镜描述（与首帧图生视频同款写法），例："固定镜头，人物表情平静对着镜头说话"。
- 模式：**大师模式**（动作表情更丰富，但可能幅度过大、表情夸张）vs **快速模式**（适合固定镜头平静说话）。
- 效果：神情自然，头部摆动、五官肌肉变化、口型匹配好。
- 适用：一张图片生成对口型视频适合**固定镜头**；动态镜头可**先生成视频、后做对口型**。

### 3.6 配乐：MiniMax
- 国内生成音乐效果最好的平台之一；也有 TTS 功能（可选模型/音色），但**不能调参数和情绪**，故配音不推荐。
- **音乐创作**：填歌曲名称 + 歌词（自写或 AI 辅助）+ 风格描述（可含制作要求）；开「纯音乐」开关则免歌词，只描述曲风（例："咖啡厅轻松舒缓的背景音乐"）；可设一次生成数量。
- 效果：契合提示词、主次分明。

### 3.7 快速找现成配乐
- 非商用作品可直接用剪映「音频」→ **音乐库**搜索（如搜"咖啡厅"），效果接近 AI 生成。

## 四、剪辑成片（p14，剪映为例）

### 4.1 剪映界面四大区域
1. 左上方**素材选择区**（导入音视频素材）；2. 中间**效果预览区**；3. 右上方**参数查看/调整区**（随选中对象变化：音量、色调等）；4. **剪辑轨道**（裁剪、排序、声画匹配、转场）。

### 4.2 素材区常用功能
- 拖拽素材到轨道；删除、Ctrl+Z 撤销、Ctrl+Shift+Z 取消撤销。
- 官方素材：色卡（黑白图做转场过渡）、"Fail moments later" 快进转场等（剪生活视频常用，剪短剧少用）。
- **音频**：音乐库（官方 BGM，可搜索）+ 音效库（剪映会员免费有版权，如煮咖啡注沸音效）。
- **文本**：加文字/字幕；AI 旁白（添加口播稿→配音选择→加轨道，直接生成带字幕的配音）。
- 贴纸、特效（滤镜）剪短剧少用；**转场**用得多：常用**叠化**（上镜头渐隐、下镜头渐显）；转场要符合剧情氛围（回忆→闪白/闪回、异常情况→故障效果）；添加后播放预览判断是否合适。

### 4.3 预览区与片段衔接（关键）
- 播放起点由轨道上**白色指针**决定。
- **导出当前画面**（预览窗右上方）：AI 视频除首帧外画面不可控，下一段想无缝衔接时，把上一段**结尾画面导出为首帧图**去生成新片段（示例：导出苏总结尾画面 → 用它生成"助理走来俯身汇报项目"的下一个镜头）。导出可命名、设分辨率/格式、选择是否同时加入素材库。

### 4.4 参数调节区
- 视频参数：大小缩放、左右移动、旋转、变形、描边；AI 功能（补帧、AI 扩展画面、AI 消除）很少用——生成前已确保分镜图/人物/场景无错误。
- 抠图、蒙版、美颜；**音频选项**：换音色（就在此位置）、音量、淡入淡出、自动响度统一、降噪、人声美化。
- 动画效果：入场动画（逐渐显现、破碎等）；常用"出场渐暗"让镜头结束自然过渡到下一镜头。
- 选中音频时只显示音频参数：**淡入淡出**时长（开头渐大=淡入、结尾渐小=淡出），也可直接在轨道上拖拽小云圈设置。
- 转场参数：可调持续时长（叠化默认 0.5 秒，可加长）。

### 4.5 剪辑轨道操作
- 视图缩放：放大镜+尺子图标快速缩到全局（粗剪）；拖右侧滑块放大到帧级（精剪）。
- 分割与裁剪：**预览轴**（黄线，可开关）；选中片段（白框）→ **Ctrl+B 分割**（某些版本直接按 B）；**Q 键删光标左侧、W 键删右侧**；或点上方三个对应按键。
- 移动：拖拽即可；**主轨道默认向左磁吸**（保证视频连续），可关闭磁吸（磁铁图标）或把片段移到其他轨道避免吸附；**转场必须在同一轨道上才能添加**。
- 音频操作与视频一致（裁长短、移位置），注意**声画匹配**（煮咖啡画面与沸腾声同时出现）；白色指针在片段分割位置附近有自动吸附，方便精确对齐。
- **图层分层（类似 PS）**：声音可叠加多层且上下顺序无所谓——示例三层：①咖啡厅 BGM 贯穿全片 ②煮咖啡注沸声 ③餐厅人群嘈杂声，注意各自音量配比；视频片段**上层覆盖下层**，缩小上层尺寸可做**画中画**；小眼睛=隐藏画面轨道、小喇叭=静音音频轨道。

### 4.6 字幕添加
- Ctrl+A 全选轨道所有文件 → 右键「**新建复合片段**」（所有素材归入一个文件夹）→ 再右键复合片段 →「**识别字幕**」→ 自动生成。
- 修改任一字幕的位置/大小/字形，**其他字幕同步生效**。

### 4.7 实操技巧（易忽略点）
1. **环境音**：餐厅戏除 BGM 外要加人群嘈杂声（微弱但不可缺，去掉能明显察觉差异）；户外戏加风声、街道声——新手最易忽略，记得加整体环境音。
2. **短剧结尾音效**：音效库搜"短剧结尾"，有"咚"一声打鼓式震撼音效，类型丰富。

### 4.8 成片交付
- 按脚本顺序导入编号片段 → 粗剪排布 → 精剪对齐 → 加转场/淡入淡出 → 配 BGM+音效+环境音 → 复合片段+识别字幕 → 预览导出。
- 系列课程成品示例对白（供复刻参考）：破产求前妻再帮一次 → "离婚协议写得很清楚，两清" → 前妻公司逆袭签约、股价上涨 → "当初你弃我如敝履，如今我站在你够不着的高度" → 结尾反转："父母生病就是骗你的……到时候看我怎么拿捏你"。
